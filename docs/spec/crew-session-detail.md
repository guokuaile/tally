# 小刻会话详情与工牌

## 问题

小刻下拉列表以色点和文字呈现会话，难以快速辨认状态；等待时缺少具体请求，运行及完成时缺少最近动作。工牌字段和项目称呼也需要更贴近团队设定。

## 不做什么

不在 Tally 内批准权限、回答问题或执行命令；不接入模型生成摘要、不上传会话内容，Claude 增加只读的 PermissionRequest hook，旧安装需重新点击安装；不改变已有状态判定。

## 方案选型

- 推荐：沿用现有 hook 与 transcript 数据，在有可靠来源时展示简短详情；无法确定时省略。下拉每行用状态图标、状态文字和标题，工牌保留现有角色画风。代价是不同 agent 可提供的详情不一定相同，需限制读写与刷新成本。
- 仅修改界面：用现有状态文字和完成消息，不新增详情采集。改动较小，但无法满足等待原因和最近动作。
- 常驻独立事件服务：实时汇聚完整事件流。可以提供更多细节，但引入常驻服务和新通信边界，与当前轻量本机设计不符。

## 模块表

| id | 模块 | 职责 | 单向依赖 | 顺序 |
|---|---|---|---|---|
| detail | 会话详情 | 解析可靠的等待内容和最近动作 | 既有会话及本地事件 | 1 |
| crew | 小刻列表 | 展示状态与可用详情，选择会话跳转 | detail | 2 |
| badge | 工牌 | 展示部门、岗位和角色文案 | 既有会话 | 1 |

## 设计

- 等待时展示当前请求或问题的可确认摘要；运行及完成展示可确认的最近工具动作或修改文件，明确标注「最近」，不声称是任务总结。显示文本限制长度并去除换行；空值、过期或无法归属会话时不显示。
- 详情是可选数据，旧记录没有时正常读取。等待详情随等待结束清除，动作详情不因后台子 agent 混入而误归主会话；不改变原 `updated_at`、状态排序和等候计时语义。采集方式以各 provider 可证实的事件或 transcript 为准，无法可靠得到的类型不臆造。
- 列表左侧使用可区分的状态图标并配状态文字，不仅靠颜色；展示标题、模型和可用详情，保留逐行跳终端、滚动和可访问性。调整行高时同步面板高度与屏幕约束。
- 部门为目录名加「项目组」，小刻下拉标题同步；岗位为应用名加模型，模型未知时只显示应用名。工牌增加「不喜欢」「小秘密」，每个角色的四项文案有趣且稳定，不暗示真实用户数据。布局容纳六项，不裁切，保留减少动态效果和无障碍标签。
- hook 保持校验失败不写、永远退出 0、900 毫秒退出及原有并发语义。任何新详情不得发送网络；敏感命令或文本可能被屏幕旁人看到，沿用现有截屏隐藏设置。

## 任务与验证点

| # | 行为 | 文件或表面 | 命令 | 标准 |
|---|---|---|---|---|
| 1 | 详情来自正确事件，过期、缺失和旧数据安全退化 | detail、hook、会话 | `swift test --filter HookRunnerTests`；`swift test --filter SessionModelTests` | 新增来源、清除、并发与旧格式用例通过，原有状态用例不回归 |
| 2 | 多会话列表可辨认状态并显示可用详情 | crew | `swift test`；`./scripts/install.sh --build` | 全部测试通过，真机悬停多状态列表，逐行点击定位正确，截图可读 |
| 3 | 工牌显示六项且内容完整 | badge | `swift test`；`./scripts/install.sh --build` | 角色文案及模型缺失用例通过，真机工牌完整，减少动态效果和 VoiceOver 标签正确 |

任务 1 跨 hook、共享模型和 app，属于同一条端到端数据链；各来源可用性须先通过隔离夹具和交互会话验证，不能保证未知 provider 必有详情。

## 预算与停止

20 分钟没有新证据，或同一路径失败两次，停止并报告；复审三轮仍有阻断项则重新比较方案。实施前核对当前工作区，保留其他未提交修改。

## Review Focus

1. 并发子 agent 与主会话的请求归属（任务 1）。
2. 等待已结束后旧请求残留或旧动作误标为当前（任务 1）。
3. 未知事件格式、过长文本及旧格式记录（任务 1）。
4. 面板行高变化导致裁切或点击目标错位（任务 2）。
5. 长目录、长模型和工牌六行溢出（任务 3）。

## 影响面

会话共享模型、hook、app 读取与小刻展示；旧记录兼容，失败时隐藏详情。不开网络、不更改权限；关闭或移除新展示可回退到原有状态视图。安装脚本会替换本机 `/Applications/Tally.app` 并接管实例，按项目要求在验证通过后执行。
