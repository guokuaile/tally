# 显示器与壁纸

设置窗口有「显示器」「壁纸」两个分区，刘海「系统」页顶部展示硬件与电池，接着采用左右卡片：第一行显示器 / 壁纸，第二行保持唤醒 / 清洁锁；压力信息放在最下方。每张卡分开标题、主状态、辅助说明与操作，设置入口位于右上角。系统页出现时及屏幕配置变化时只刷新显示器数据，不自动切换；快捷按钮沿用系统页黑底上的浅色胶囊。显示器按需应用；壁纸由 app 内附带的独立播放器持续运行。关闭设置或退出 Tally 不会改回显示档位，也不会停止壁纸。

## 显示器

使用公开 CoreGraphics API 读取显示器、当前模式与可用模式，按显示器 UUID 保存选择。档位同时记录逻辑尺寸、渲染像素尺寸与刷新率，区分普通缩放和 HiDPI。设置中的「应用所选模式」立即应用下拉框选择，无需先保存；「保存为常用」只保存系统页快捷应用的目标，不切屏。当前已经是所选模式时明确提示无需切换，成功、失败与处理中状态在操作旁显示。「刷新显示器」只重读列表并显示数量；设置页解释新增档位的安装、重连、刷新、选择应用步骤。系统设置仍可以改分辨率，Tally 不在后台抢回。

应用前持久化待确认记录，切换后重新读取当前档位才记为成功。撤销针对上一次成功应用，只有当前档位仍等于 Tally 当时应用的档位时才允许恢复；从系统设置改过后，旧撤销失效，避免覆盖后续调整。读取失败和显示器拔出显示明确错误，不能盲目回滚。首次 CLI 工具留下的原始基线与 Tally 的「上一次」分开处理。

新增 HiDPI 档位先检查尺寸、渲染上限与屏幕比例，预览后由系统管理员弹窗授权写入显示器 override。提权进程再次核验固定目标路径、目录、备份与现有内容，拒绝符号链接或被其他工具修改的文件。原始配置只备份一次，重复安装不能覆盖原始备份；中断后的恢复也要核对已记录内容。配置恢复和显示档位撤销是不同操作。新档位可能需要重新连接显示器才能被系统枚举；不替用户关 SIP、不写私有 SkyLight 模式、不承诺提升面板物理像素。

规格与验收边界见 [显示档位规格](spec/display-presets.md) 和 [桌面控制规格](spec/desktop-controls.md)。

## 壁纸

素材以独立列表行呈现，每项有目录或文件图标、名称、次要路径和移除按钮；通过原生选择器添加目录或文件，重复路径不重复加入。移除仅修改待保存的播放列表，不删除磁盘文件；保存后才更新播放器。设置 10 秒至 24 小时的轮播间隔（默认 5 分钟）。图片与视频混排、随机不重复，新素材优先；视频静音循环，同一素材同步显示在各块屏幕。按屏幕像素解码图片，保留 EXIF 方向、等比铺满和淡入淡出；窗口在桌面图标下方，不拦鼠标。空目录回到系统壁纸，无法读取的素材显示错误。

「开始 / 停止」控制本次播放，「登录后播放」控制下次登录，二者独立。手动暂停持久保存；屏幕休眠临时暂停，唤醒不能覆盖手动暂停。暂停、继续、下一张、重新扫描都通过仅当前用户可访问的本地 socket 发给播放器，以实际回复更新状态。

播放器是 `Contents/Library/LoginItems/TallyWallpaper.app/Contents/MacOS/tally-wallpaper`，无 Python 或终端脚本运行依赖。配置、播放状态、历史和有大小上限的日志放在 `~/Library/Application Support/Tally/Wallpaper/`。运行任务定义为该目录的 `player-agent.plist`，标签 `com.aiden.tally.wallpaper`；开启登录播放时才在 `~/Library/LaunchAgents/` 保留相应 plist。进程锁防止重复播放器；退出 Tally 后任务继续运行。

首次接管现有 `com.aiden.video-wallpaper` 时，先校验新播放器和素材，记录旧任务状态，停旧后启动新任务并检查 IPC。失败则撤回新任务并恢复旧任务，原 plist、脚本、二进制和素材均保留。卸载前在壁纸设置关闭登录播放并停止；需要回到旧播放器时使用恢复旧服务操作，再移除 Tally。

## 验证

`swift test` 覆盖模式匹配、事务撤销、HiDPI 输入与配置恢复、壁纸配置、播放队列、控制协议和服务迁移。`python3 -m unittest discover -s Tests/ScriptTests` 在临时目录模拟安装成功与失败恢复。`./scripts/install.sh --build` 后从真实设置页验证切换 / 撤销、播放控制、旧服务接管及退出 Tally 后继续播放；重新连接显示器与实际重启只在确实做过时算已验证。
